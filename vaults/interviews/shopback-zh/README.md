# ShopBack 面试准备指南

## 面试形式

你的面试包含 **2 轮**（共 2 小时 15 分钟）：

| 轮次   | 时长   | 平台              | 重点                         |
| ------ | ------ | ----------------- | ---------------------------- |
| 第二轮 | 1 小时 | HackerRank（实时）| 技术评估 - 实时编程          |
| _休息_ | 15 分钟| -                 | -                            |
| 第三轮 | 1 小时 | HackerRank（实时）| 领域知识 - 系统设计          |

## 学习计划

### 面试前一周

**第 1-3 天：编程基础**

- 复习 LeetCode 简单到中等难度的模式（数组、哈希表、字符串、贪心）
- 每天在 HackerRank 环境中练习 2-3 道题
- 注重代码整洁、解释清晰

**第 4-5 天：系统设计**

- 学习返现追踪系统（最可能出现的领域问题）
- 复习事件驱动架构模式
- 练习绘制架构图

**第 6-7 天：打磨**

- 模拟面试并计时（每轮 1 小时）
- 复习 ShopBack 公司概况以了解背景
- 准备行为面试故事（STAR 格式）

### 面试当天

- 提前 30 分钟测试 HackerRank 环境
- 准备好纸笔用于系统设计草图
- 牢记 ShopBack 的规模数据（5500 万用户、每日 50 万笔交易、13 个市场）
