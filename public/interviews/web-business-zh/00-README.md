# Web 业务知识手册

一份写给 Web 开发者的业务常识指南。不讲代码，只讲业务——帮你搞懂你写的代码背后到底在做什么生意。

## 为什么要写这个？

你可以是个很厉害的程序员，但换了个新公司、新行业，照样会懵。产品经理说"我们要加催缴逻辑"、"要过 PCI 合规"，你得知道他在说啥。这些文章就是帮你补上这块短板。

## 怎么用？

每篇文章结构一样：

- **这是什么？** — 大白话解释
- **为什么要懂？** — 不懂的话会踩什么坑
- **业务流程** — 一步步走完整个流程
- **常见术语** — PM、运营、老板嘴里的那些词
- **常见模式** — 大多数公司怎么做的
- **踩坑提醒** — 不懂业务的开发最容易犯的错
- **速查表** — 快速回顾用的精简版
