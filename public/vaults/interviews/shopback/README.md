# ShopBack Interview Preparation Guide

## Interview Format

Your interview consists of **2 rounds** (2h15m total):

| Round   | Duration | Platform          | Focus                              |
| ------- | -------- | ----------------- | ---------------------------------- |
| Round 2 | 1 hour   | HackerRank (Live) | Technical Assessment - Live Coding |
| _Break_ | 15 min   | -                 | -                                  |
| Round 3 | 1 hour   | HackerRank (Live) | Domain Knowledge - System Design   |

## Study Plan

### Week Before Interview

**Days 1-3: Coding Fundamentals**

- Review LeetCode Easy-Medium patterns (arrays, hash maps, strings, greedy)
- Practice 2-3 problems daily on HackerRank environment
- Focus on clean, well-explained code

**Days 4-5: System Design**

- Study cashback tracking system (most likely domain question)
- Review event-driven architecture patterns
- Practice drawing architecture diagrams

**Days 6-7: Polish**

- Mock interview with timer (1 hour each round)
- Review ShopBack company overview for context
- Prepare behavioral stories (STAR format)

### Day of Interview

- Test HackerRank environment 30 min before
- Have pen/paper ready for system design sketching
- Keep ShopBack's scale numbers in mind (55M users, 500K daily txns, 13 markets)
